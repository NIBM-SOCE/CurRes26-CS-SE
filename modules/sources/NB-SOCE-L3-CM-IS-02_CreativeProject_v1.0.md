## 2. Module Purpose and Aims

To give every first-year student the experience of taking a creative computing idea from conception to a demonstrated artefact, in a team, with structure: scoping, planning, iterative building, public demonstration and reflection. The module is one of the two designed vehicles for the public project portfolio that export-facing recruitment screens for, and the first place teamwork is formally practised and assessed.

### Specification Boundary (canonical, v8.1 Phase 2)

> **Covers:** team-based creative computing project practice: ideation, scoping and planning; iterative building; public demonstration; structured reflection.
>
> **Does NOT cover:** the integrative capstone experience (Capstone Project, Year 2); taught technical content (owned by the taught modules whose skills the project applies).
>
> *The boundary text is the audited canonical text, identical wherever carried. Any change is a change request against the Master Decisions register, not a descriptor-level edit.*

## 4. Skills Programme and Delivery

### Workshop Programme

| Ref | Theme | Hours |
|---|---|---|
| W1 | Ideation and project framing: from interest to idea | 3 |
| W2 | From idea to plan: scoping, roles and timeline | 3 |
| W3 | Making I: build practices, tooling and iteration | 3 |
| W4 | Making II: reviewing progress and adapting the plan | 3 |
| W5 | Showing I: demonstration craft and storytelling | 3 |
| W6 | Showing II: rehearsal and feedback | 3 |
| W7 | Reflection: process, teamwork and lessons | 3 |
| W8 | Portfolio: presenting the project publicly | 3 |
|  | Total workshop hours | 24 |

Workshops run as eight three-hour blocks (V10 session pattern). Facilitated activities (30 hours) are supervised team build sessions; coaching (12 hours) is per-team progress review; independent work (84 hours) is the team build itself plus the individual reflective piece.

## 5. Assessment

Components per the Assessment Component Taxonomy (04_Conventions.md). Weightings confirmed at specification sign-off; no formal examination is carried by design (skills module).

| Component code | Task | Attributes | ILOs | Weight |
|---|---|---|---|---|
| CW-G-Home | Team project: working artefact, build log and public demonstration; team size recorded per cohort plan (indicatively n = 4), with an individually maintained contribution log per student securing individual accountability | Group (n = 4 indicative); take-home with supervised build sessions; graded; oral vehicle: Presentation | LO1, LO2, LO3 | 60 |
