## 2. Module Purpose and Aims

To build the foundational professional communication every SOCE graduate needs from the first year: clear structured writing, confident spoken presentation with visual support, and the habit of adapting register to audience and purpose. Delivery is workshop-based and practice-heavy: students communicate about their own computing work from the start, so artefacts double as early portfolio evidence.

### Specification Boundary (canonical, v8.1 Phase 2)

> **Covers:** foundational written, spoken and visual communication for academic and professional audiences; audience and register adaptation; collaborative communication and feedback practice.
>
> **Does NOT cover:** advanced workplace and career communication (Effective Communication Skills II); discipline-specific technical documentation depth (pathway modules where relevant).
>
> *The boundary text is the audited canonical text, identical wherever carried. Any change is a change request against the Master Decisions register, not a descriptor-level edit.*

## 4. Skills Programme and Delivery

### Workshop Programme

| Ref | Theme | Hours |
|---|---|---|
| W1 | Foundations of professional communication: audience, purpose and register | 3 |
| W2 | Written communication: structure, clarity and technical-writing basics | 3 |
| W3 | Spoken communication and presentation fundamentals | 3 |
| W4 | Visual communication: slides, diagrams and document design | 3 |
| W5 | Collaborative communication: teams, meetings and feedback | 3 |
|  | Total workshop hours | 15 |

Workshops run as five three-hour blocks (V10 session pattern). Facilitated activities (21 hours) are practice studios applying each workshop theme to the student's own computing work; coaching sessions (9 hours) give structured feedback on developing portfolio pieces; independent work (55 hours) completes the portfolio.

## 5. Assessment

Components per the Assessment Component Taxonomy (04_Conventions.md). Weightings confirmed at specification sign-off; no formal examination is carried by design (skills module).

| Component code | Task | Attributes | ILOs | Weight |
|---|---|---|---|---|
| CW-I-Home | Communication portfolio: two written artefacts (one academic, one professional register) and one visual-communication artefact, developed through the coaching cycle | Individual; take-home; graded; oral vehicle: None | LO1, LO3, LO4 | 60 |
| CW-I-Class | Structured individual presentation with visual support, delivered to a workshop audience with question handling | Individual; in-class; graded; oral vehicle: Presentation | LO2, LO3 | 40 |

Reassessment: by the failed component only, with an equivalent task, per School regulations. All assessment under the academic integrity policy including its generative-AI provisions; module-level AI stance at teaching-plan stage.
